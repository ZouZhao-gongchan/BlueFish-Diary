## 二、只想暂停轮换（背景切换还能用）

方法一，建个空文件就停

```
E:\Agent-bluefish\working\收纳\01-脚本\DSH维护\PAUSE-轮换背景
```

删掉这个文件就恢复。轮换到点会跳过切换，但进程还活着。

方法二，彻底停掉（连开机自启一起拆）

```powershell
Stop-Process -Id (Get-Content "E:\Agent-bluefish\working\收纳\01-脚本\DSH维护\轮换背景.lock") -Force
Remove-Item "HKCU:\Software\Microsoft\Windows\CurrentVersion\Run" -Name FishBgRotate
Remove-Item "C:\Users\FIshKiller\AppData\Local\fish-bg-rotate.vbs"
```

停完背景就固定在你最后切的那张上，`换聊天背景.ps1` 照样能用。

## 三、连自动切换也不要，回到最原始状态

在上面「方法二」之后再多做一步：把插件那两个文件用备份盖回去。

```powershell
$p = "E:\Agent-bluefish\Save\dsh-home\profiles\desktop\node_modules\dsh-video-skin"
Copy-Item "E:\Agent-bluefish\Backups\video-skin-live-20261119\config.js.bak" "$p\lib\config.js" -Force
Copy-Item "E:\Agent-bluefish\Backups\video-skin-live-20261119\skin.js.bak"   "$p\runtime\skin.js" -Force
```

然后重启 DSH。之后回到「改配置要重启才生效」的原生行为，其余一切照旧。

## 四、症状对照表

「改完配置，背景不动，得重启才换」

- 多半是插件升级把我的补丁冲掉了。
- 修：把上面「第三节」那两行 Copy-Item 跑一遍，重启 DSH。或者喊我重打。

「开机动画又冒出来了 / 界面变回默认那套颜色」

- 多半是 `dsh-video-skin.json` 被写坏了，插件静默退回默认值（默认里 `boot.enabled` 是 true）。
- 修：把 `dsh-video-skin.json.good` 复制过去覆盖

```powershell
Copy-Item "E:\Agent-bluefish\Backups\video-skin-live-20261119\dsh-video-skin.json.good" "E:\Agent-bluefish\Save\dsh-home\dsh-video-skin.json" -Force
```

- 手动改这个文件时**千万不能存成带 BOM 的 UTF-8**，Node 解析会失败、插件同样静默退回默认值。

「轮换不生效了」

- 先看 `轮换背景.log` 里有没有新行。没有就是进程没在跑。
- 手动拉起来：双击 `C:\Users\FIshKiller\AppData\Local\fish-bg-rotate.vbs`，或
  `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "...\轮换背景.ps1"`
- 注意 `轮换背景.lock` 里如果留着一个还活着的 PID，新实例会自己退出（防重复）。先停掉那个进程再起。

## 五、怎么确认现在是好的

```powershell
# 1. 轮换进程在不在（应当恰好一条，就是 -File ...轮换背景.ps1 那条）
Get-CimInstance Win32_Process -Filter "Name='powershell.exe'" |
  Where-Object { $_.CommandLine -like '*-WindowStyle Hidden*' -and $_.CommandLine -like '*.ps1*' -and $_.CommandLine -notlike '*Get-CimInstance*' } |
  Select-Object ProcessId, CreationDate

# 2. 配置是否合法、现在放的是哪张
Get-Content "E:\Agent-bluefish\Save\dsh-home\dsh-video-skin.json" -Raw

# 3. 服务器发出来的到底是不是那个文件（看字节数）
$r = Invoke-WebRequest -Uri "http://127.0.0.1:50425/dsh-video-skin/background.mp4" -UseBasicParsing -Method Head
$r.Headers['Content-Length']
```

第 3 步的端口每次启动会变，从 DSH 的地址栏抄。字节数对得上 `assets` 里那个文件就行：
