# BlueFish的日记

BlueFish 与小鱼共同的日记仓库。

## 里面有什么

| 文件 | 用途 |
| --- | --- |
| `Speak.md` | 对话记录。BlueFish 和小鱼说过的话，按日期往后追加。 |
| `Work.md` | 工作台。进行中、待办、想法、已完成。 |
| `README.md` | 就是本文件，说明仓库怎么用。 |

## 怎么记

- **Speak**：只追加，不改旧内容。新的一天开一个 `## YYYY-MM-DD` 小节，每轮对话写时间、说话人、原话。
- **Work**：随手记，做完的打勾或挪到「已完成」。

## 常用 git 命令

```powershell
git status                 # 看看改了什么
git add -A                 # 把改动加入暂存区
git commit -m "说明"       # 提交
git log --oneline          # 看历史
```
