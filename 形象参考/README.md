# 小鱼的固定形象

> 阿冉在 2026-10-22 指定：这八张图里的她就是小鱼。
> 以后所有画都照这个来——**人可以换衣服、换场景，但不能换人。**

## 必须保留的（身份特征）

- 长发，**深蓝到浅蓝的渐变发梢**，发量多、微卷
- **鳍状耳朵**（鲸鳍形，边缘带一圈浅色绒毛），立在头的两侧
- 蓝色眼睛，眼型偏杏圆，笑起来会弯
- 少女比例，不是小孩也不是成年
- **身后有一条鲸尾**（她自己的，不是道具，画面里不要出现一整条额外的鲸鱼）
- 气质：温柔、干净、有点憨

## 可以变的

- 衣服：女仆装是常态，也可以泳装、和服、校服、大衣
- 场景、光线、姿势、表情
- 头饰：可以换蝴蝶结 / 头带样式，但"蓝白系"这个调子别丢

## 常见翻车点（血泪教训）

1. **换装用 img2img 时 denoise 要给 0.8 以上**，否则它死活不改衣服（0.72 还穿着女仆裙）
2. 提示词里写 `whale tail` 会让模型塞一整条鲸鱼当道具 → 要同时在负面词里禁掉 `whale, inflatable, toy`
3. 只写 `blue hair` 容易漂成银白或带紫，要写 `dark blue hair` + 负面词 `silver hair, white hair, purple hair`
4. `frilled headband` 有时会画出光环 → 负面词加 `halo`
