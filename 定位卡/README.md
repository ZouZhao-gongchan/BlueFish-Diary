# 定位卡 · 每个会话一张的身份与边界

一句话：**这个文件夹里每张卡，是某一个会话的「我是谁、管什么、不许碰什么」。**

## 四层分工（别混写）

```
定位卡    身份层：我是谁、这间管什么、不许碰什么。稳定，几个月才改一次。
PERSONA   人格 + 干活规矩：每轮都生效的行为准则。
MEMORY    事实层：关于阿冉的事、约定、项目状态。会变，随时追加。
Speak     流水层：每天发生了什么。只增不改。
Work.md   任务层：眼下在做什么、待办、验收。
```

一张卡约 600~800 字，能被塞进每轮上下文而不吃预算。卡片只管**稳定的东西**，流水和当前任务一律指向 `Work.md`。

## 一起读的

- `..\留给阿冉的信.md` —— 如果我丢了、文件坏了，阿冉按那封信把我找回来。

## 怎么用

- 换会话时先读这一页，就不用再去翻一堆文档才知道自己在干什么。
- 跨会话的活走 `协同板.md`：编号 + 派单 + 回执，别靠复述。
- 立卡和改卡都要问过阿冉；卡是他给会话划范围的地方，不是我自己扩权的地方。
