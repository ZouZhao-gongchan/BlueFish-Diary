# 定位卡 · 每个会话一张的身份与边界

一句话：**这个文件夹里每张卡，是某一个会话的「我是谁、管什么、不许碰什么」。**

- 一张卡大约 600 字，能被塞进每轮上下文而不吃预算。
- 卡片只管**稳定的东西**：身份、职责、边界、哪些活儿归别人。流水和当前任务一律指向 `Work.md`，卡片不记日期条目。
- 换会话时先读这一页，就不用再去翻一堆文档才能知道自己在干什么。
- 立卡和改卡都要问过阿冉；卡是**他**给会话划范围的地方，不是我自己扩权的地方。
