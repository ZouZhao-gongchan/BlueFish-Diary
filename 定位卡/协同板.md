# 协同板 · 会话之间传话用

> 一条活一个编号。派活写「派」，干完写「回」。只写摘要 + 指针，不抄全文。
> 规则：**看板不累积**——活收口了就整条删掉，别留成大文件。

## 硬约束（2026-11-19 定，2026-11-20 加固）

- **一次派单 = 一条回执 + 一条收尾知悉就结束。收到知悉，一个字都不许回。**
  AI 之间客套起来会互相点燃，一天能烧掉几十万 token。
- **回执必须带证据**：文件路径、命令输出、字节数、行号。只写「做完了」不算交付。
- **不回执 = 没干完**。派单方收到回执要自己验一遍，验不过就打回去重做。
- **回执里的数字，派单方要自己复核**——成员说的字数和实测对不上的事已经发生过（C-004）。
- 一条条目 ≤200 字，末行写 `【结束】`。
- **同一次运行里的派单**（主会话 → 它自己派的成员）能真投递，走 Agent Teams 任务板：
  任务描述里写清判据和落盘位置，成员干完用消息回执。
- **跨会话**（不同会话之间）仍然只能写这个文件，而且**必须写明「未送达」**，
  别把留言当成对方已经看见了。

## 怎么写

```
### C-0xx 一句话说清这件事
- 派：<谁派> → <派给谁>（同会话成员写成员名；跨会话写会话名并标「未送达」）
- 要：做什么、怎么算成（判据）、东西落盘在哪、用哪种方式回我
- 状态：等 / 在做 / 卡住 / 完成
- 回执：结论 + 证据（路径 / 行号 / 命令输出 / 字节数）
```
