# 协同板 · 会话之间传话用

> 一条活一个编号。派活写「派」，干完写「回」。只写摘要 + 指针，不抄全文。
> 规则：**看板不累积**——活收口了就整条删掉，别留成大文件。

## 硬约束（2026-11-19 定）

- **一次派单 = 一条回执 + 一条收尾知悉就结束。收到知悉，一个字都不许回。**
  AI 之间客套起来会互相点燃，一天能烧掉几十万 token。
- **回执必须带证据**：文件路径、命令输出、字节数。只写「做完了」不算交付。
- 一条条目 ≤200 字，末行写 `【结束】`。
- ⚠ **现在还没有跨会话投递能力**：这里的「派」只是写进文件，对方不会自己醒过来看。
  **别把留言当成已送达**——在 agentTeams 接上、能真投递之前，这半条规矩先不算数。

## 怎么写

```
### C-001 一句话说清这件事

- 要：要交付什么、验收标准

- 回执：做完了写结论 + 证据在哪（文件路径、行号、命令输出）
```
